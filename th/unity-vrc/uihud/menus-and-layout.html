เมนู, hotbar และ world panel

HUD, ปุ่มบนมือถือ, ปุ่มบนข้อมือ และเมนูแต่ละตัว มี canvas ของตัวเอง

เมนู​

UIHudMenu เลื่อนเข้าจาก side ที่ตั้งไว้: Left, Right, Top, Bottom หรือ Center

ปุ่มหลัก​

ปุ่ม M, ปุ่มบนข้อมือใน VR และปุ่ม MENU บนมือถือ ทำหน้าที่เป็นปุ่มหลักปุ่มเดียวกัน

สถานะปุ่มหลักทำอะไร
ไม่มีเมนูหลักเปิดอยู่เปิดเมนูทุกตัวที่เปิด Open with main button ไว้ แม้จะมีเมนูอื่นเปิดอยู่แล้ว
มีเมนูหลักเปิดอยู่ปิดเมนูที่เปิดอยู่ทั้งหมด

ปุ่มหลักไม่เปิดหรือปิด world panel

เมนูที่มีปุ่มของตัวเอง​

ใน Inspector ของเมนู ให้ตั้ง Own desktop key เช่น Q หรือเปิด Own wrist & mobile button ถ้าต้องการให้เมนูเปิดแยกต่างหาก ให้ปิด Open with main button

พฤติกรรม​

  • เมนูเปิดในแนวระดับเสมอ แม้คุณจะเอียงหัว
  • การสั่งเปิดเมนูที่เปิดอยู่แล้วจะคงเมนูไว้ที่เดิม ปุ่มในเมนูจึงใช้สลับหน้าได้
  • บน desktop และ VR เมนูอยู่ตรงจุดที่เปิด และปิดเมื่อคุณเดินห่างออกไปเท่า Auto Close Distance (ค่าเริ่มต้น 2.5) ส่วนบนมือถือเมนูจะตามกล้อง
  • ระหว่างผู้เล่นพิมพ์ใน UIHudInput ระบบจะไม่รับปุ่มเมนูและปุ่ม hotbar 1–9 สำหรับช่องข้อความบน world panel ที่อยู่นอก object UIHUD ให้ตั้งฟิลด์ Manager

Hotbar​

สร้างด้วย GameObject > UIHUD > Hotbar หรือ Hotbar > Add hotbar บน manager เริ่มต้นมี 6 slot child ทุกตัวของ canvas คือ slot และ Add slot ▾ รับ widget ได้หลายชนิด ไม่ได้มีแค่ปุ่ม

hotbar แยกจาก HUD การซ่อนอย่างหนึ่งจึงไม่ซ่อนอีกอย่าง

แพลตฟอร์มตำแหน่งวิธีใช้
VRใต้ระดับสายตาก้มมองแล้วชี้ที่ slot
Desktopใต้มุมมองก้มมองแล้วคลิก หรือกด 1–9
มือถือด้านล่างของจอแตะที่ slot

ใน VR และ desktop hotbar ตามตำแหน่งของคุณ แต่คงทิศเดิมไว้ระหว่างที่คุณหมุนตัว

การตั้งค่าค่าเริ่มต้นความหมาย
vrAngle45มุมก้มจากระดับสายตา (องศา)
vrDistance0.6ระยะห่างเป็นเมตร ปรับตามความสูงของอวาตาร์
followTurnAfter90หมุนกลับมาข้างหน้าหลังคุณหันไปเกินมุมนี้ 0 = หมุนตามเสมอ, 180 = ไม่หมุนตาม
vrTurnSmoothing8ความนุ่มนวลตอนหมุนกลับ
desktopLockToBodyเปิดถ้าปิดจะตรึงไว้ด้านล่างของจอ
mobileLockToBodyปิดถ้าเปิดจะยึดกับลำตัวเหมือนใน VR

Show on ใช้เปิดหรือปิดแยกตามแพลตฟอร์ม เมื่อกด slot ที่เป็นปุ่ม slot นั้นจะถูกเลือก, เปลี่ยนสีเป็น selectedColor และส่ง Event ของ hotbar พร้อม index ของ slot ค่า -1 หมายถึงไม่ได้เลือก

World panel​

GameObject > UIHUD > World Panel (standalone) สร้างเมนูที่อยู่ตรงจุดที่คุณวาง สำหรับ kiosk, บอร์ด หรือร้านค้า ไม่ต้องมี manager เมนูใดก็สลับระหว่าง Player view และ World (standalone) ได้ใน Inspector

ตัวเลือกความหมาย
Visible at startแสดงตั้งแต่โหลด world
Scale (mm per px)ค่าเริ่มต้น 1 ดังนั้น 1200 × 820 px คือ 1.2 × 0.82 ม.
Move in front of the Scene cameraย้าย panel ไปตรงจุดที่คุณกำลังมอง

เปิด panel ที่ปิดไปแล้วอีกครั้งด้วย UIHudButton (Menu To Toggle หรือ Open Menu) หรือเรียก Open()

Container​

Row, Grid, Scroll และ Pages ใส่ widget ได้ทุกชนิด รวมถึง container อื่น ซ้อนได้ไม่จำกัดชั้น Pages ใช้แท็บด้านบนหรือด้านซ้าย หรือตัวเลือกแบบ < name > ได้ Scroll เป็นแนวตั้งหรือแนวนอนก็ได้ ถ้าต้องการให้ widget ไม่อยู่ใน layout แบบรายการ ให้เปิด Absolute position

เครื่องมือใน editor​

  • หน้าต่าง preview (Window > UIHUD Preview): แสดง HUD, เมนู หรือ world panel แบบเดียวกับในเกม คลิกเพื่อเลือก widget และ Alt+คลิก เลือกชิ้นส่วนตรงจุด
  • Style: New สร้าง Assets/UIHUD Style.asset asset นี้ใช้ใน editor เท่านั้น มันเปลี่ยนหน้าตาของ object ใน scene และไม่มีอะไรอ่านมันตอน runtime

กฎ UI ของ VRChat​

ตัว builder ตั้งค่าเหล่านี้ให้แล้ว ถ้าสร้างชิ้นส่วนเองให้ทำตามด้วย

กฎเหตุผล
canvas ใช้ layer Walkthroughpointer ของ VRChat ไม่สนใจ UI และ UiMenu เว้นแต่เมนูของ VRChat เปิดอยู่
Ui Shape และ BoxCollider ของมันอยู่บน object เดียวกับ Canvascanvas แต่ละตัวจะรับการชี้เฉพาะพื้นที่ของตัวเอง
ปิด Focus View บน canvas ที่ติดกับผู้เล่นฟีเจอร์นี้ต้องให้ผู้เล่นอยู่ห่างอย่างน้อย 0.6 ม.
มี EventSystem หนึ่งตัวพอดีจำเป็นสำหรับการรับ input ของ UI
Navigation เป็น Noneปุ่มเคลื่อนที่จะไม่ไปเปลี่ยนค่า control
ปิด Raycast Target บนข้อความป้ายข้อความจะไม่บังปุ่ม
เมธอดของ event เป็น publicUI เรียกด้วยชื่อ

ผู้เล่น desktop เล็งด้วย crosshair หรือกด Tab ค้างเพื่อใช้เคอร์เซอร์อิสระ

บันทึก

Hide HUD From Camera (เปิดเป็นค่าเริ่มต้น) ย้าย HUD ไปที่ layer UI รูปถ่ายจากกล้องของ VRChat จึงไม่ติด HUD เว้นแต่จะเปิดตัวเลือก UI ของกล้อง hotbar มีตัวเลือกเดียวกัน ส่วนเมนูซ่อนด้วยวิธีนี้ไม่ได้ เพราะ pointer ของ VRChat ไม่สนใจ layer นั้น

เกม standalone​

เมื่อไม่มี VRChat SDK:

  • กล้องหลักคือหัว และเท้าอยู่ต่ำลงไป 1.6 ม. ถ้าต้องการตัวละครจริงให้เพิ่ม UIHudStandalonePlayer
  • เมาส์และการแตะใช้ EventSystem กับ StandaloneInputModule ส่วนปุ่มลัดบนคีย์บอร์ดต้องตั้ง Active Input Handling เป็น Input Manager หรือ Both
  • การชี้ด้วย controller ของ VR ต้องใช้ XR UI input module ของคุณเอง
  • UIHUD ใช้ unscaled time เมนูจึงทำงานได้ขณะเกมหยุดชั่วคราว
  • การ sync ผ่าน network ไม่ทำอะไร และ Networking.IsOwner เป็น true เสมอ
  • ฉากตัวอย่าง Examples ใช้ได้ใน VRChat เท่านั้น
