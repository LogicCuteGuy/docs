# Localization ของข้อความและ Asset

> เวอร์ชันเอกสาร: **0.5.0**

Localization ไม่ได้เป็นส่วนหนึ่งของ LCGUdonSharp แล้ว ตั้งแต่ 0.4.0 ย้ายไปเป็นแพ็กเกจแยก [**LCG Localization**](../lcglocalization/intro.md) (`com.logiccuteguy.lcglocalization`) ซึ่งใช้ได้กับ UdonSharp ของ VRChat SDK และ LCGUdonSharp

## ย้ายโปรเจกต์เดิม

1. ติดตั้ง **LCG Localization** คู่กับ LCGUdonSharp
2. scene เดิมยังอ้างอิงได้ เพราะ GUID ของสคริปต์ไม่เปลี่ยน
3. เมนูอยู่ใต้ **Tools > LCG Localization**
