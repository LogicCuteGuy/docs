# การ bake ทำงานอย่างไร

ZoneDraw แปลงจุดที่วาดให้เป็น collider ธรรมดาของ Unity ใต้ object ลูกชื่อ `_ZoneColliders` ส่วน component `ZoneShape` ที่ใช้วาดมีไว้ใน editor เท่านั้น VRChat จะตัดออกตอน build แต่ collider ที่ bake แล้วยังอยู่

## bake เมื่อไร

เมื่อเปิด **Auto Bake** รูปทรงจะ bake ใหม่หลังแก้ไข ถ้ากำลังลากจุดหรือลูกศรความสูง จะ bake ตอนปล่อยเมาส์ Undo และ Redo ก็ bake ใหม่เช่นกัน ถ้าปิด Auto Bake ให้กด **Bake Colliders** ส่วน **Remove Colliders** จะลบ object `_ZoneColliders`

Prefab asset จะไม่ถูก bake ให้ bake บน prefab instance ในฉาก หรือแก้ใน Prefab Mode

การ bake ครั้งถัดไปจะเขียนทับ object ลูกที่สร้างไว้ จึงไม่ควรแก้ด้วยมือ object เหล่านี้ใช้ layer เดียวกับ object ที่มี `ZoneShape` ถ้าจะเปลี่ยน ให้เปลี่ยน layer ของ object นั้นแล้ว bake ใหม่

## กำแพง Barrier

แต่ละช่วงระหว่างสองจุดจะเป็น `BoxCollider` หนึ่งอัน ชื่อ `Wall 0`, `Wall 1` ไปเรื่อย ๆ ถ้าเปิด **Closed** และมีอย่างน้อย 3 จุด จะมีกำแพงเพิ่มอีกด้านเชื่อมจุดสุดท้ายกับจุดแรก

กล่องแต่ละอันยาวเลยจุดปลายออกไป เพื่อให้มุมซ้อนกันและไม่มีช่องโหว่

| Wall Faces | ความหนาอยู่ด้านไหน |
|---|---|
| **Front** | ด้านขวาตามลำดับจุด |
| **Back** | ด้านซ้ายตามลำดับจุด |
| ทั้งสองด้าน | อยู่กึ่งกลางเส้น |

**Reverse** กลับลำดับจุด ซึ่งจะสลับ Front กับ Back ถ้าเลือกด้านเดียว ส่วนที่ยาวเกินอาจโผล่เลยมุมด้านในเล็กน้อย หากเป็นปัญหาให้ใช้ทั้งสองด้านหรือลดความหนา

## ปริมาตร Zone

Zone ต้องมีอย่างน้อย 3 จุด แต่ละจุดถูกยืดขึ้นตาม **Height** และลงตาม **Bottom Offset**

| Polygon | ผลลัพธ์ |
|---|---|
| Convex (นูน) | `MeshCollider` แบบ convex หนึ่งอัน |
| Concave (เว้า) | `MeshCollider` แบบ convex หนึ่งอันต่อสามเหลี่ยม |

รูปเว้าที่มีจุดเยอะจึงสร้าง collider จำนวนมาก และเส้นของ polygon ต้องไม่ตัดกันเอง เพราะการแบ่งสามเหลี่ยมรองรับไม่ได้ Inspector จะแสดงจำนวนจุดและจำนวน collider

เมื่อเปลี่ยนเป็น **Zone** ด้วยแถบเลือกโหมด **Is Trigger** จะเปิดให้ ถ้าเปลี่ยนเป็น **Barrier** จะปิด

## พื้นและเพดาน

**Ground Collider** และ **Ceiling Collider** ต้องใช้กับรูปที่ปิดวง (zone หรือ barrier ที่เปิด **Closed**) และมีอย่างน้อย 3 จุด แผ่นทั้งสองหนาตามค่า **Thickness**:

- ผิวบนของพื้นอยู่ที่จุดที่วาด
- ผิวล่างของเพดานอยู่ที่ยอดของรูปทรง

## Mesh ที่มองเห็นได้

ใส่ **Render Material** เพื่อให้มองเห็นรูปทรง เช่น ทำเป็นสนามพลังหรือรั้ว

- Mesh แสดงผลสองด้าน
- UV ต่อซ้ำตามขนาดจริงในโลก โดยใช้ความสูงกำแพงเป็นหน่วย texture จึงไม่ยืดบนกำแพงยาว
- Zone จะมีหน้าด้านบนด้วย เว้นแต่ปิด **Render Top** แผ่นพื้นและเพดานก็มีหน้าเช่นกัน
- renderer ที่สร้างใหม่จะปิดเงาไว้ ค่าที่แก้ภายหลังจะไม่หายเมื่อ bake ใหม่

## การวางจุด

| ตัวเลือก | การทำงาน |
|---|---|
| **Snap To Surface** | จุดจะลงบน collider ใต้เคอร์เซอร์ โดยข้าม trigger และ collider ของรูปทรงเอง ถ้าไม่โดนอะไรจะลงบนระนาบแบน |
| **Grid Snap** | ปัดค่า X และ Z ของโลกตามระยะนี้ ค่า 0 คือปิด |
| **Drop To Ground** | ย้ายแต่ละจุดลงไปยังพื้นผิวที่สูงที่สุด โดยยิง ray ลงจาก 50 m เหนือจุด |
| **Flatten** | ตั้ง local Y ของทุกจุดเป็น 0 |
