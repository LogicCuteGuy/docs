# メニュー、ホットバー、ワールドパネル

HUD、モバイルボタン、手首ボタン、各メニューは、それぞれ専用のキャンバスを持ちます。

## メニュー

`UIHudMenu` は設定した **side**（Left、Right、Top、Bottom、Center）からスライドします。

### メインボタン

**M** キー、VR の手首ボタン、モバイルの **MENU** ボタンは、1 つのメインボタンとして働きます。

| 状態 | メインボタンの動作 |
|---|---|
| メインメニューが開いていない | ほかのメニューが開いていても、**Open with main button** が有効なメニューをすべて開きます |
| メインメニューが開いている | 開いているメニューをすべて閉じます |

ワールドパネルは開閉しません。

### 専用キーを持つメニュー

メニューの Inspector で **Own desktop key**（例: **Q**）を設定するか、**Own wrist & mobile button** を有効にします。個別に開くメニューは **Open with main button** を無効にします。

### 動作

- 頭を傾けていても、メニューは常に水平に開きます。
- 開いているメニューをもう一度開くと位置は変わらないため、メニュー内のボタンでページを切り替えられます。
- デスクトップと VR では、メニューは開いた場所に留まり、**Auto Close Distance**（既定 2.5）以上離れると閉じます。モバイルではカメラに追従します。
- `UIHudInput` に入力中は、メニューキーとホットバーの 1〜9 キーを無視します。`UIHUD` オブジェクトの外にあるワールドパネルのテキスト入力には、**Manager** フィールドを設定してください。

## ホットバー

**GameObject > UIHUD > Hotbar** か、マネージャーの **Hotbar > Add hotbar** で作成します。最初は 6 スロットです。キャンバスの子はすべてスロットで、**Add slot ▾** ではボタン以外の多くの種類も追加できます。

ホットバーは HUD と独立しているため、片方を非表示にしてももう片方は残ります。

| プラットフォーム | 位置 | 操作方法 |
|---|---|---|
| VR | 目線より下 | 下を向いてスロットを指します |
| Desktop | 視界の下 | 下を向いてクリックするか、**1**〜**9** を押します |
| Mobile | 画面下部 | スロットをタップします |

VR とデスクトップでは位置に追従しますが、体を回している間は向きを保ちます。

| 設定 | 既定値 | 意味 |
|---|---|---|
| `vrAngle` | 45 | 目線から下向きの角度 |
| `vrDistance` | 0.6 | 距離（メートル）。アバターの身長に合わせて拡大縮小します |
| `followTurnAfter` | 90 | この角度を超えて回ると正面に戻ります。0 = 常に追従、180 = 追従しません。 |
| `vrTurnSmoothing` | 8 | 戻るときの滑らかさ |
| `desktopLockToBody` | 有効 | 無効にすると画面下部に固定します |
| `mobileLockToBody` | 無効 | 有効にすると VR のように体に固定します |

**Show on** でプラットフォームごとに有効・無効を切り替えます。ボタンのスロットを押すと選択状態になり、`selectedColor` で色が付き、ホットバーの **Event** がスロット番号とともに送られます。-1 は未選択です。

## ワールドパネル

**GameObject > UIHUD > World Panel (standalone)** は、置いた場所に固定されるメニューを作成します。キオスク、掲示板、ショップに使えます。マネージャーは不要です。どのメニューも Inspector で **Player view** と **World (standalone)** を切り替えられます。

| オプション | 意味 |
|---|---|
| **Visible at start** | ワールドの読み込み時に表示します |
| **Scale (mm per px)** | 既定は 1 で、1200 × 820 px は 1.2 × 0.82 m になります |
| **Move in front of the Scene camera** | 現在見ている場所にパネルを移動します |

閉じたパネルは、`UIHudButton`（**Menu To Toggle** または **Open Menu**）か `Open()` で再び開きます。

## コンテナー

Row、Grid、Scroll、Pages には、ほかのコンテナーを含むどのウィジェットも、何段でも入れられます。Pages は上か左のタブ、または `< name >` 形式のセレクターを使えます。Scroll は縦か横を選べます。リストレイアウトから外すには、ウィジェットの **Absolute position** を有効にします。

## エディターツール

- **プレビューウィンドウ**（**Window > UIHUD Preview**）: HUD、メニュー、ワールドパネルをゲーム内と同じように表示します。クリックでウィジェットを選び、Alt+クリックで該当の部品を選びます。
- **Style:** **New** は `Assets/UIHUD Style.asset` を作成します。このアセットはエディターでのみ使います。シーンのオブジェクトの見た目を書き換えるもので、実行時には読み込まれません。

## VRChat の UI ルール

ビルダーはこれらを設定済みです。部品を手作業で作る場合も守ってください。

| ルール | 理由 |
|---|---|
| キャンバスは **Walkthrough** レイヤーを使う | VRChat のメニューを開いていない間、VRChat のポインターは UI と UiMenu を無視します |
| **Ui Shape** とその BoxCollider を Canvas のオブジェクトに置く | 各キャンバスが自分の範囲だけを受け付けます |
| プレイヤーに追従するキャンバスは **Focus View** を無効にする | プレイヤーが 0.6 m 以上離れている必要があるためです |
| EventSystem は 1 つだけ | UI の入力に必要です |
| **Navigation** は None | 移動の入力でコントロールが変わらないようにします |
| テキストの **Raycast Target** は無効 | ラベルがボタンを遮らないようにします |
| イベントのメソッドは public | UI が名前で呼び出します |

デスクトップのプレイヤーは照準で狙うか、**Tab** を押し続けてカーソルを自由にします。

:::note
**Hide HUD From Camera**（既定で有効）は HUD を UI レイヤーに移します。カメラの UI オプションが有効でない限り、VRChat のカメラ写真に HUD は写りません。ホットバーにも同じオプションがあります。VRChat のポインターはそのレイヤーを無視するため、メニューはこの方法では隠せません。
:::

## スタンドアロンゲーム

VRChat SDK がない場合:

- メインカメラが頭で、足はその 1.6 m 下です。実際のキャラクターには **UIHudStandalonePlayer** を追加します。
- マウスとタッチは、EventSystem と StandaloneInputModule を使います。キーボードショートカットには、**Active Input Handling** の **Input Manager** か **Both** が必要です。
- VR コントローラーで指すには、独自の XR UI 入力モジュールが必要です。
- UIHUD は unscaled time を使うため、ゲームの一時停止中もメニューが動きます。
- ネットワーク同期は何もせず、`Networking.IsOwner` は常に true です。
- Examples のサンプルシーンは VRChat でのみ動作します。
