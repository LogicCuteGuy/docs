# StreamData をはじめる

## 1. コンポーネントを設定する

1. シーンを保存します。
2. GameObject を作成し、**StreamData** UdonSharp ビヘイビアを追加します。
3. ストリーミングするマテリアルを **Stream Materials** に追加します。そのカラーテクスチャ（sRGB、テクスチャタイプ Default）が対象です。

| 設定 | 初期値 | 意味 |
|---|---|---|
| **Base Url** | | 書き出したファイルがあるフォルダーの URL。末尾は `/`。 |
| **Backup Base Url** | | 2 つ目のホスト（任意）。 |
| **Fallback Size** | 128 | ワールドに含めるテクスチャの長辺。 |
| **Max Stream Size** | 1024 | ストリーミングするテクスチャの長辺（最大 2048）。 |
| **Stream Lightmaps** | オフ | シーンのカラーライトマップもストリーミングします。 |
| **Lightmap Ship Size** | 0 | 0 より大きい場合、Export Stream がシーンのライトマップテクスチャの Max Size をこの値にします。 |
| **Load Distance** | 0 | この距離（メートル）内のテクスチャをダウンロードします。0 はすべてを近い順に取得し、解放しません。 |
| **Unload Factor** | 1.5 | Load Distance × この値より遠いテクスチャは代替テクスチャに戻ります。 |

:::note
**Lightmap Ship Size** はライトマップテクスチャのインポート設定を変更します。
:::

## 2. 書き出す

**Export Stream** をクリックします。フルサイズのデータを `<scene>_StreamData/Export~` に書き出し、代替テクスチャを作成します。テクスチャ、マテリアル、URL を変えたら書き出し直してください。

元のマテリアルは変更されません。ビルドと Play モードでは、代替テクスチャを使うコピーが使われます。

## 3. エディターでテストする

**Base Url** を `http://localhost:8765/` のような localhost のアドレスにして書き出し、**Start Test Server** をクリックします。サーバーは localhost でのみ待ち受け、各リクエストを Console に記録します。下記の公開設定をしている場合は、**Play Mode Uses Export~** が自動でこれを行います。

## 4. 公開する

**Tools > StreamData > Publish** を開いてホストを選びます。

:::warning 公開は誰でも閲覧でき、既定で自動です
ホストを設定すると、Build & Test を含むすべての VRChat ビルドでエクスポートと公開が行われます。最初のビルドの前に[ストリームデータの公開](./publishing.md)を読んでください。
:::

## 実行時の動作

最初に `manifest` ファイルをダウンロードします。オフラインや URL がブロックされている場合などで失敗すると、画像は要求されず、代替テクスチャのままになります。その後、プレイヤーに近い順に画像を 1 枚ずつダウンロードします。VRChat の制限は 5 秒に画像 1 枚なので、大きなワールドでは読み込みに時間がかかります。

**Baked** の項目は編集しないでください。Export Stream が書き込みます。

## トラブルシューティング

| 症状 | 確認すること |
|---|---|
| テクスチャがぼやけたまま | Base Url + `manifest` をブラウザーで開きます。URL が `/` で終わること、最後の書き出し後に公開したことを確認します。 |
| 自分の PC では動くが他の人では動かない | ホストが `*.github.io` ではないため、プレイヤーは Allow Untrusted URLs が必要です。 |
| 変更したテクスチャが反映されない | 書き出して公開し直します。URL を変えた場合はワールドを再アップロードします。 |
| 公開中にビルドが停止する | Console のエラーを確認して **Check gh Login** を実行するか、**Publish On Build** をオフにします。 |
