# ベイクの仕組み

ZoneDraw は描いた点を、子オブジェクト `_ZoneColliders` の下の通常の Unity コライダーに変換します。描画に使う `ZoneShape` コンポーネントはエディター専用で、VRChat のビルドからは削除され、ベイク済みのコライダーだけが残ります。

## ベイクされるタイミング

**Auto Bake** がオンの場合、編集のたびに再ベイクします。点や高さの矢印をドラッグしている間は、マウスを離したときにベイクします。Undo と Redo でも再ベイクします。オフの場合は **Bake Colliders** を押します。**Remove Colliders** は `_ZoneColliders` を削除します。

プレハブアセットはベイクされません。シーン上のプレハブインスタンスか Prefab Mode でベイクしてください。

生成された子オブジェクトは次のベイクで上書きされるので、手で編集しないでください。レイヤーは `ZoneShape` を持つオブジェクトと同じです。変えるには、そのオブジェクトのレイヤーを変更して再ベイクします。

## Barrier の壁

2 点間の各区間が 1 つの `BoxCollider`（`Wall 0`、`Wall 1` …）になります。**Closed** がオンで 3 点以上あると、最後の点と最初の点を結ぶ壁が追加されます。

角に隙間ができないよう、各ボックスは端点より少し長く作られます。

| Wall Faces | 厚みの向き |
|---|---|
| **Front** | 点の順序に対して右側 |
| **Back** | 点の順序に対して左側 |
| 両方 | 線を中心にする |

**Reverse** は点の順序を反転し、Front と Back が入れ替わります。片側だけの場合、延長した部分が内側の角から少しはみ出すことがあります。気になる場合は両側にするか、厚みを減らしてください。

## Zone のボリューム

Zone には 3 点以上が必要です。各点は **Height** だけ上に、**Bottom Offset** だけ下に押し出されます。

| ポリゴン | 結果 |
|---|---|
| 凸 | convex の `MeshCollider` が 1 つ |
| 凹 | 三角形ごとに convex の `MeshCollider` が 1 つ |

そのため、点の多い凹形状はコライダーが多くなります。三角形分割ができないので、辺が交差するポリゴンは使えません。点とコライダーの数は Inspector に表示されます。

モードのツールバーで **Zone** に切り替えると **Is Trigger** がオンに、**Barrier** に切り替えるとオフになります。

## 床と天井

**Ground Collider** と **Ceiling Collider** は、閉じた形状（Zone、または **Closed** をオンにした Barrier）で 3 点以上必要です。どちらも **Thickness** の厚みを持ちます。

- 床は上面が描いた点の高さになります。
- 天井は下面が形状の上端になります。

## 表示用メッシュ

**Render Material** を設定すると、フォースフィールドやフェンスのように形状を表示できます。

- メッシュは両面表示です。
- UV は壁の高さを単位としてワールドサイズでタイリングされるので、長い壁でもテクスチャが伸びません。
- Zone は **Render Top** をオフにしない限り上面も描きます。床と天井のスラブにも面が付きます。
- 新しく作られたレンダラーは影がオフです。後で変更した設定は再ベイク後も残ります。

## 点の配置

| オプション | 動作 |
|---|---|
| **Snap To Surface** | カーソル下のコライダー上に配置します。トリガーと自分のコライダーは無視します。何もなければ平面上に配置します。 |
| **Grid Snap** | ワールドの X と Z をこの間隔に丸めます。0 で無効です。 |
| **Drop To Ground** | 各点の 50 m 上から下向きにレイを飛ばし、最も高い面に移動します。 |
| **Flatten** | すべての点のローカル Y を 0 にします。 |
