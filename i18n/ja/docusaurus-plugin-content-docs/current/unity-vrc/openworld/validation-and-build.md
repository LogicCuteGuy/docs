# 検証とビルドオプション

**Tools > OpenWorld > Validation** を開くか、OpenWorld Settings の **Validate** を押します。エラーがあると VRChat のビルドは停止します。警告では停止しません。

## 予算

Mid リング内のチャンクで最も重い範囲を、すべて視界内にあるとみなして確認します。

| 予算 | PC | Quest |
|---|---|---|
| ドローコール | 400 | 150 |
| 三角形 | 1,000,000 | 150,000 |
| 常駐するストリーミングテクスチャ | 512 MB | 128 MB |
| Mid リングの推奨上限 | 3 | 2 |

予算超過は警告です。Block は種類ごとに 1023 インスタンスで 1 ドローと数え、インポスターのページを加えます。Terrain、Dig Zone、エンティティ、アバターは含みません。これらは Quest 実機で未計測の初期値です。

## エラー

| 内容 | 対処 |
|---|---|
| グリッドが空 | Chunk Size、Chunks X、Chunks Z を設定します。 |
| チャンクルートがグリッドと一致しない | **Assign To Chunks** を押します。 |
| Near リングが Mid リングより大きい | Near を減らすか Mid を増やします。 |
| Merge Rings × Block Chunks + 1 | Mid リングより大きくします。 |
| グリッド内のオブジェクトがチャンクルートにない | **Assign To Chunks** を押します。 |
| Block Prefabs が未ベイク、または Block の配置が古い | **Assign To Chunks** を押します。 |
| Block の種類のメッシュかマテリアルがない | **Assign To Chunks** を押します。 |
| マテリアルの GPU Instancing がオフ | オンにします。オフだと Block が描画されません。 |
| チャンクのコライダーが未ベイク | **Assign To Chunks** を押します。 |
| Editable のワールドでリージョンごとの編集マネージャーがない | **Assign To Chunks** を押します。 |

## 警告

| 警告 | 対応 |
|---|---|
| レンダラーが 2 チャンクより広い | 分割します。1 つのチャンクと一緒に現れて消えます。 |
| Quest か PC の Mid リングが推奨値を超える | 減らすか、計測します。 |
| Quest で 1 フレームのチャンク切り替えが 2 件以上 | カクつきを避けるため 1 にします。 |
| インポスターが未ベイク | **Bake Impostors** を押します。ないと遠くのチャンクは何も表示されません。 |
| ドローコールが多すぎる | メッシュを結合するか、Block を使うか、Mid リングを減らします。 |
| 三角形が多すぎる | 軽いメッシュを使うか、Mid リングを減らします。 |
| ストリーミングテクスチャのメモリが多すぎる | OpenWorldStream の **Load Distance** を設定するか、画像を小さくします。 |

## ビルドオプション

**OpenWorld Settings** にあります。

| オプション | 効果 | トレードオフ |
|---|---|---|
| **Bake On Build** | VRChat のビルド前に毎回、チャンクの再割り当て、地形の木の再読み込み、インポスターのベイク、シーン保存を行います | ビルドが長くなる |
| **Strip Detail Maps** | シーンのマテリアルから法線、メタリック／スペキュラ、オクルージョン、高さ、ディテールの各マップを外し、平坦に描画します | ダウンロードは小さく、見た目は平坦になる |
| **No Static Batching** | 静的バッチングを無効にします | ダウンロードが大幅に小さくなり、ドローコールは増える |
| **Unbatch Repeated Meshes** | この数以上のレンダラーが共有するメッシュを静的バッチングから外します（0 で無効） | そのメッシュは 1 回だけ収録されます。マテリアルで GPU Instancing を有効にしてください。 |

マテリアル関連のオプションはコピーに対して適用されるので、元のマテリアルは変わりません。

## チャンクのギズモ

| オプション | 表示内容 |
|---|---|
| **Show Chunk Boxes** | 各チャンクの内容を囲むボックス。Play モードでは緑が Near、黄が Mid、灰がオフです。 |
| **Show Chunk Details** | チャンクごとの名前、Block、地形の木、コライダー（ワールド選択中のみ） |
| **Details Distance** | Scene カメラからラベルを描く距離 |
| **Show Chunk Borders** | Scene カメラがいるチャンクの境界線 |
