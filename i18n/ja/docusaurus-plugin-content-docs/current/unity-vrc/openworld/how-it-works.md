# OpenWorld の仕組み

## 空間の構成

ワールドは XZ 平面上の**チャンク**のグリッドです。チャンクは読み込みと描画バッチの単位です。8 × 8 チャンクをまとめたものが**リージョン**で、VRChat はダウンロードの頻度を制限するため、リージョンがネットワークダウンロードの単位になります。設計上の目標は約 1 km²（32 m チャンク、32 × 32 グリッド）です。

編集シーンは作成した階層のままです。チャンクルート、Block、インポスターは、Play モードとビルドで使うシーンのコピーにだけ作られます。

## コンテンツの種類

| 種類 | GameObject | 描画方法 | 主な用途 |
|---|---|---|---|
| **Block** | なし（データのみ、コライダーは残る） | GPU インスタンシング | 机、木、壁、岩 |
| **Grid Block** | Block と同じ | GPU インスタンシング | セルに吸着する床、壁、草 |
| **Block Entity** | あり（チャンクと一緒にストリーミング） | 通常のレンダラー | ドア、スイッチ |
| **Chunk Entity** | あり（プール可能） | 通常のレンダラー、リングでカリング | NPC、ピックアップ |
| **Terrain**（任意） | DigHoleIt のゾーン | DigHoleIt | 掘れる地面 |

## 実行時の動作

OpenWorld はプレイヤーのいるチャンクを調べます。変わると新しいリングを計算し、近い順にチャンクの切り替えをキューに入れます。1 フレームで実行するのは最大 **Changes Per Frame** 件です。

| リング | 内容 |
|---|---|
| Near | メッシュとコライダー |
| Mid | メッシュのみ |
| Mid のすぐ外 | チャンクごとにインポスター 1 枚 |
| さらに遠く | チャンクのまとまりごとにインポスター 1 枚 |

**インポスター**は、半八面体上の多数の方向から撮影したチャンクの画像を表示するカードです。シェーダーが視線の角度に合うフレームを選びます。

| 設定 | 既定値 | 意味 |
|---|---|---|
| **Impostor Frames** | 8 | チャンクインポスターの 1 辺あたりの撮影方向数。多いほど回り込みが滑らかです。 |
| **Impostor Frame Size** | 32 | 1 フレームのピクセル数。テクスチャメモリは frames × size の 2 乗で増えます。 |
| **Impostor Block Chunks** | 4 | まとめるブロックの 1 辺のチャンク数 |
| **Impostor Merge Rings** | 2 | 自分の周囲で、まだチャンクインポスターを使うブロック数 |
| **Block Impostor Frames / Frame Size** | 8 / 64 | まとめたブロック用の同じ 2 つの値 |

**Merge Rings × Block Chunks + 1** が Mid リングより大きくないと、検証でエラーになります。

## Block の描画

Block は `VRCGraphics.DrawMeshInstanced` と、用意したインスタンシング対応マテリアルで描画します。配置はベイクしたデータから読み、[StreamData](../streamdata/intro.md) でダウンロードすることもできるので、アップロード後にレイアウトを変更できます。VRChat は実行時に新しいメッシュを読み込めないため、メッシュとマテリアルはワールドに含めておく必要があります。

## Grid Block

各チャンクには **64 × 64 セル**の**レイヤーが 5 つ**あります。1 セルには、レイヤーごとに Block を 1 つまで置けます。レイヤーは分類で、それぞれ高さのモードを持ちます。

| 既定のレイヤー | 高さのモード |
|---|---|
| Ground | Base Y 500 より下で見つかった床の上 |
| Ground Decoration | Base Y 500 より下で見つかった床の上 |
| Underground | Base Y −32 からの固定ステップ |
| Building | Base Y 0 からの固定ステップ |
| Roof | Base Y 0 からの固定ステップ |

高さは **Step** メートル（既定 0.25）単位の 256 段階です。床の高さは実行時ではなく**ベイク時**に下向きのレイキャストで求めます。レイヤーごとに **Floor Mask** があります。床に当たらないセルは除外され、ベイクが警告します。上の階の床には、Base Y をその階の天井のすぐ下に置くと、レイが屋根で止まりません。

Grid Prefab ごとに次を設定できます。

- **Layer** と **Also On**: 最初のレイヤーに置けない場合に使う別のレイヤー。下から順に配置するので、1 つの壁プレハブを 2 階分積めます。
- **Footprint**: 各方向 1〜15 セル。オブジェクトのヨー角を 90° 単位にして回転します。既定の 1 × 1 はアンカーセルのみを使います。

位置はセルの角（チャンクサイズ ÷ 64）に、ヨー角は 22.5° 単位に吸着します。実行時のデコードは複数フレームに分散します。再デコード中のチャンクは、新しい Block の準備ができるまで古いものを描画します。

## ストリーミングするライトマップとテクスチャ

ワールドには小さな代替テクスチャが含まれるので、ダウンロード完了前や失敗時も動作します。[StreamData の仕組み](../streamdata/how-it-works.md)を参照してください。
