# テキストとアセットのローカライズ

> ドキュメントバージョン: **0.5.0**

ローカライズは LCGUdonSharp に含まれなくなりました。0.4.0 で別パッケージの [**LCG Localization**](../lcglocalization/intro.md)（`com.logiccuteguy.lcglocalization`）に移りました。VRChat SDK の UdonSharp と LCGUdonSharp で動作します。

## 既存プロジェクトの移行

1. LCGUdonSharp と一緒に **LCG Localization** をインストールします。
2. スクリプトの GUID は同じなので、既存シーンの参照は維持されます。
3. メニューは **Tools > LCG Localization** にあります。
