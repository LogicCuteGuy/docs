# サンプル

サンプルはパッケージの `Example/` フォルダーにあり、デモシーンは `Showcase.unity` です。各フォルダーに Rust のソース、ビルド済みの `.wasm`、UdonSharp スクリプト、README があります。

| サンプル | 内容 | 技術 |
|---|---|---|
| **Mandelbrot** | 視点を同期するフラクタル画像 | 64 KB のパレットを定数データに |
| **Juno6** | 演奏できるポリフォニックシンセ | 音声レンダリング、MIDI、ネットワークイベント |
| **AudioDsp** | 音声フィルター | GPU 上の FIR フィルター |
| **DeepZoom** | 深いマンデルブロズーム | `f64`、bands、リードバックなし |
| **SimdPlasma** | アニメーションするプラズマ | `v128` SIMD、リードバックなし |
| **Chroma** | 音階に合わせるライブフィルター | リアルタイム音声処理 |

DeepZoom と SimdPlasma は **Tools > WASM2HLSL > Add f64 + SIMD Examples To Scene** で追加できます。追加後はシーンを保存してください。

## Mandelbrot

メイン画像とジュリア集合は各 256 × 256 です。視点番号は同期され、**Interact** で次の視点に進みます。

## Juno6

C2〜C5 を演奏できる 12 ボイスのシンセサイザーです。`VRCMidiListener` で MIDI を受け取ります（VRChat を `--midi=<device>` で起動します）。パネルの値は同期され、ノートはネットワークイベントで送ります。

キーごとに 32 kHz ステレオ 3 秒分（約 230 万個の値）を 30〜90 ms でレンダリングし、0〜2 秒を 1 回再生してから 2〜3 秒をループします。各ピクセルは独立して計算されるため、直前の 256 サンプルに対してフィルターをやり直して、サンプルごとに状態を再現します。

## AudioDsp

98,304 サンプル（512 × 192 テクスチャ）のスイープを、カットオフが 2 秒ごとに 200 Hz から 8 kHz へ動く 65 タップの FIR フィルターで処理します。**Interact** で off、dry、sweep を切り替え、選択は同期されます。

## DeepZoom

`f64` による 256 × 256 のズームで、倍率を 32 回 2 倍にできます。`f32` では約 17 回で破綻します。8 バンドでは 1 フレーム約 3.5 ms、画像全体で約 27 ms です。

:::note
このシェーダーのコンパイルには約 1 分かかります。
:::

結果は Node.js と一致します。`WASM2HLSL/Int Display` の **Iteration Palette** モードで表示します。

## SimdPlasma

SIMD で計算するプラズマで、**Packed RGBA8** モードで表示します。コンパイルは 1 秒未満で、色の値の基準との差はバイトあたり 1 以内です。

## Chroma

ライブ音声を音階の音に合わせてフィルタリングします。パネルには **Color**（0〜200）、**Key**、**Scale**（5 種類）、品質切り替え（HQ はレイテンシ 43 ms、LOW は 21 ms）、**Bypass** があります。音声ブロックあたりの GPU 時間は約 0.7 ms、バッファは 50〜80 ms です。

:::note
Chroma の README にある **Add Chroma Chain To Scene** は作者のプロジェクト側のメニューで、**パッケージには含まれません**。
:::

## 再ビルド

サンプルは 1 KB のスタック（`-zstack-size=1024`）でビルドしています。コマンドは各フォルダーの README、一般的なビルドフラグは[はじめに](./getting-started.md)を参照してください。

このページの時間はパッケージのサンプル README の値です。GPU によって数値は変わります。
